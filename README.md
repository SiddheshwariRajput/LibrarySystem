📚 Library Management System

📖 About the Project

The Library Management System is a web-based application designed to manage library operations efficiently. It helps users manage library members and maintain library records digitally.

🚀 Features

- Add new library members
- Manage member details
- Store and manage library records
- User-friendly interface
- Database connectivity
- Efficient record management

🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask)
- Database: SQLite
- Code Editor: Visual Studio Code

⚙️ Installation and Setup

1. Clone the repository:

git clone YOUR_REPOSITORY_URL

2. Open the project folder:

cd LibrarySystem

3. Install Flask:

pip install flask

4. Run the application:

python app.py

5. Open your browser and visit:

http://127.0.0.1:5000/

🎯 Objective

The main objective of this project is to simplify library management by reducing manual work and providing an organized way to maintain library records.
